## 1. The Ten Emergent Design Principles

1. **Strict pipeline ordering.** Calculate → interpret; condition → outcome;
   object → authority → topic → timing → quarantine. Gates before output.
   Calculation validity never validates interpretation.
2. **Object-tagged authority resolution.** "Ruler of WHAT?" — authority type
   is part of the record, not a synonym. Prevents generic-role collapse.
3. **Condition-state logic.** Every factor carries mutable state; outcomes
   are functions of nature × condition × role — never absolute. States can
   invert expected behavior.
4. **Method pluralism with witness preservation.** Parallel methods stay
   separate families; fallback/substitution gates define precedence without
   merging; uncertainty is graded, never silently normalized.
5. **Topic-driven routing.** The inquiry domain selects the starting frame
   before any computation.
6. **Directed-graph semantics.** Transmissions are directed edges with
   transmitter/receiver condition; A→B ≠ B→A; remainders route via
   opposition; recurrence ≠ identical manifestation.
7. **Typed numerics + dependency visibility.** Every value carries
   VALUE+UNIT+SCALE+FUNCTION+SOURCE_LOCUS+SOURCE_LAYER+OWNER. The same
   integer polymorphs across scales — every re-scale must be explicit.
   Ordinal ≠ completed count.
8. **Safety as a first-class layer.** Quarantine attaches to claims, not
   sources; suppression gates, hard stops, and bounded result states are
   part of the procedure itself. Fail-closed halt states are valid outputs.
9. **Evidence-as-test-vector.** Worked examples verify reconstructed
   apparatus; the ledger separates stated data, procedure stack, transmitted
   result, uncertainty, and quarantine. "An example is a test vector, not a
   decoration."
10. **Anti-premature-coherence.** Staged interface maps, explicit
    open-dependency lists, and "do not synthesize yet" discipline.
    Arithmetic reproducibility ≠ selector completeness ≠ empirical validity
    ≠ authority.

## 2. State-Lineage Discipline (Book IX)

```
S0 source input → S1 normalized → S2 raw intermediate → S3 candidate
→ S4 qualified → S5 promoted → S6 result-conditioned (invalid for validation)
→ S7 blocked → S8 quarantined → S9 unresolved candidate set
```

**Laws:**
- No calculated state becomes another procedure's governing beginning
  without explicit source authorization
- Promotion (S3/S4→S5) requires a pre-declared prospective selector;
  otherwise preserve the candidate set (S9)
- No backward edges: outcome→promotion, table→cell, name→identity
- Result-conditioned states (S6) are promotion-blocked — fitted to a desired
  outcome, they cannot validate anything

## 3. Quarantine Architecture (Q0-Q10)

never source-level. Run cards execute only thin bounded actions.

## 4. Non-Identity Controls (Book VII/VIII)

Numerical coincidence never erases type distinctions:
- rising time ≠ planetary period
- minimum ≠ mean ≠ maximum period
- Lot ≠ Lot ruler ≠ occupant
- conjunction ≠ adjacent-sign contact ≠ square/opposition
- 129 months ≠ 129 days ≠ 129 hours

Interface law: an interface is an **edge**, not an identity. A match is
valid only when both sides agree on beginning, object, jurisdiction,
direction, order, value type, unit, scale, operation, output, source layer.
Shared names, shared numbers, and archive adjacency never repair missing
tables or selectors.
