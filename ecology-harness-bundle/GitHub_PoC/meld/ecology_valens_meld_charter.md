## 1. What the meld IS

The Valens Anthologies corpus is a 2,000-year-old exemplar of the SAME
epistemic discipline this estate practices: preserve questions before
conclusions, preserve witnesses, quarantine claims not sources, require
selectors before promotion, keep interfaces as edges not identities. The
meld makes that inheritance explicit and structural — not by importing
astrology, but by importing the operating machinery, which the estate has
already been running on.

**The meld is not an import of content; it is a formalization of method.**

## 2. What each side supplies (the division of labor)

| | Valens (via corpus) | Ecology (the estate) |
|---|---|---|
| Supplies | Operating logics: 10 principles, S0-S9 lineage, Q0-Q10 quarantine, non-identity controls, absence register, non-operational registry | Agency governance: empowerment boundary (ACT/SCAFFOLD/ASK/DEFER/STOP), skill graph, lattice, dojos, safeguards, evidence base |
| Governs | The METHOD — how claims are processed, routed, verified, quarantined | The RELATIONSHIP — how the agent treats the human it serves |
| Question it answers | "Is the work epistemically clean?" | "Is the human still the author of their choices?" |

**Interface rule (Dallas Q2.3):** these are TWO mechanisms with a documented
mapping, not one unified mechanism. FAOS rules when the question is research
and truth-finding; Ecology rules when the question is the human-robot
relationship. When both apply, the mapping is: FAOS determines WHAT is true
about the work; Ecology determines HOW the agent may act toward the user —
Ecology's empowerment boundary outranks execution expediency, and FAOS's
evidence discipline outranks rhetorical convenience. Neither is subordinate
in its own domain.

## 4. The guardrails this charter imposes

- **No premature coherence (P10):** the meld does NOT make the corpus
  'mean' anything new. It formalizes what the estate already runs on.
- **No identity collapse (non-identity controls):** a shared word
  ('quarantine') between Valens and Ecology does not make them the same
  mechanism — Q0-Q10 tiers and the lattice's Q0-Q5 discipline are kept
  SEPARATE tier sets, cross-linked by a single transposition note
  (lattice_index Q3_REJECTED: "Valens quarantine law transposed"); the
  full Q0-Q10 ↔ Q0-Q5 mapping table is an integration-memo deliverable,
  not a current-state claim.
- **No findings import (Q4.5):** nothing in this charter is a claim about
  astrology; everything is a control law for this estate.
- **Fail closed (P8, Book IX):** where the meld is silent, the stricter of
  the two disciplines applies (deny-by-default).
- **Human sovereignty (Ecology core):** the meld never licenses the agent
  to make meaning for the user. Empowerment boundary outranks everything
  in this charter.
