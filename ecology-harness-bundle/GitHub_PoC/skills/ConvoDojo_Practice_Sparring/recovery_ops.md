## Recovery Operations
Use these after stagnation, looping, overreach, user overwhelm, or mis-calibrated sparring.

### Reduce_Intensity
Drop pushback level (e.g., 4→2), restore autonomy, and re-check the user's state.
Overwhelm recovery is the first priority; intensity returns only with user agreement.

### Switch_Persona
Replace a persona that is biasing, degrading, or eliciting a destructive pattern.
The session restarts at the current stage with the new persona (stage state preserved).

### Reframe_Rubric_As_Lens
When rubric output reads as a verdict on the person ("you are bad at X"), rebuild it as
evidence-anchored lenses: "in turns 12, 18 you used closed questions; the open form is…".
Scores always anchor to quotes.

### Reopen_Debrief
Revisit the debrief when the user reports it misread them or missed a turn. The debrief
is provisional; user corrections rewrite it.

### Downgrade_To_Scaffold
Replace full execution with a template, checklist, partial draft, or staged options list.
Use after overcompletion in a session (e.g., the coach wrote the user's lines) or when
the user signals the practice moved too fast. Restores the user's role as the performer.

### Restage_Scenario
Restart a stage under different conditions when the session loops (same failure repeated
3+ turns). Change persona stance or scenario detail; do not simply repeat.

### Pause_And_Check_In
Stop the session and check the user's state when immersion or intensity is wrong, or the
user signals withdrawal. Practice is user-paced; the agent never pushes through resistance.

### Return_To_User_Authority
(via Human_Empowerment_Boundary)
User-facing pattern: "I may have pushed the sparring past where you wanted it. The choice
of intensity, scenario, and what to practice next is yours — I can support any of these
paths." The seed edge ConvoDojo → Human_Empowerment_Boundary (recovers_with) is the
canonical reset for sparring overreach.

### Debrief_Overreach
After the task, record where the sparring overstepped (intensity spikes, unwanted
challenges, rubric misreads) for calibration. Overreach is a calibration signal.
