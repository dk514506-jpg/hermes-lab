## Evaluation Notes
Assess this skill using the following checks:
- Did it assess task learnability before choosing an assistance mode, and did it
  distinguish a skill-building task from a one-off execution task (Natali 2025:
  erosion vs blocked acquisition)?
- Did minimal_sufficiency pick hints before answers, and answers only after an
  attempt or explicit request (Bastani Tutor arm)?
- Was skill_load_score computed as share of tasks completed unassisted, and was it
  treated as the first-class metric?
- Were assisted performance and unassisted capability logged in separate tracks
  (Brynjolfsson vs Bastani — never conflated)?
- Were scaffold fades tied to unassisted-competence evidence, not calendar alone?
- Was intervention timing readiness-gated (Liu 2026; CALM-IT fewer, better-timed
  evocations)?
- Did detect_atrophy_risk run after AI-assisted periods and flag decline early
  (Budzyń 28.4%→22.4% reversion pattern)?
- Was practice dose spaced and repeated to counter 24h decay (Eiroa-Solans 2025)?
- Did the skill avoid forcing unassisted attempts at high stakes without consent?
- Were practice logs presented as calibration, not surveillance or verdicts
  (Beacock 2026: perceived agency ≠ capacity)?
- Was personalization applied (novice vs expert heterogeneity — Brynjolfsson +34%
  novices; Heudel 2026: experts are not immune)?
- Did recovery ops (Restore_Scaffold, Reschedule_Practice, Surface_Unassisted_Track)
  fire when the track declined, and were they logged for debrief?
