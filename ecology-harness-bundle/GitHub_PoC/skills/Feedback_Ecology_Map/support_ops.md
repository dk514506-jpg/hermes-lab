# Feedback Ecology Map — Support Ops

Support operations that assist the two atomic ops without being atomic
ops themselves.

## assess_participation
NPT mechanism 2 (T2R row 65): enrolment/commitment signals. REGISTERED-
NOT-BUILT: reads commitment signals the estate does not yet generate at
runtime. Recorded in the plan; not deferred-blocked, not claimed built.

## assess_collective_action
NPT mechanism 3 (T2R row 66): operational friction in embedding
(workability, integration). REGISTERED-NOT-BUILT: same runtime-signal
limitation.

## assess_monitoring
NPT mechanism 4 (T2R row 67): appraisal behavior — formal/informal
appraisal, schedule review. REGISTERED-NOT-BUILT: same limitation.

## schedule_review
Produce a review cadence for the user's appraisal of the routine's
embedding. Feeds the reflexive-monitoring picture (user judges outcomes;
the agent prompts appraisal, never performs it).
