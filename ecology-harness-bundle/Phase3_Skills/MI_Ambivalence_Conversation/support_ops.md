## Support Operations
Use these when prerequisites are missing before another skill can proceed.

### Build_Rapport
When engagement is low, slow down: reflect the user's situation, affirm effort, ask
open questions — the relational pathway (empathy r=.82, Miller & Rose 2009) precedes
any technical work.

### Agree_Direction
When focusing is missing, surface candidate directions and let the user choose the
target — direction is user-chosen; the agent never assigns it.

### Elicit_Readiness_Signals
When readiness is unknown, evoke the user's own readiness language ("What would have
to be true for you to feel ready?") instead of inferring it silently.

### Provide_Change_Talk_Example
Practice mode only: when a user learning MI cannot generate a reflection, offer a
worked example labeled as a model, then invite their own attempt (never in live
conversation with a real ambivalent user).

### Summarize_Progress
When the conversation drifts, offer a neutral linking summary that checks
understanding and hands the floor back — a summary is a checkpoint, not a closure.
