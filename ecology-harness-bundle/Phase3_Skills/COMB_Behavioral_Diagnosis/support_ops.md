## Support Operations
Use these when prerequisites are missing before another skill can proceed.

### Specify_Target_Behavior_First
When the target behavior is vague ("be healthier", "get fit"), do not diagnose.
Pin verb + context with one question: "What would you actually be doing, where,
and how often?" COM-B behavioural target specification is the prerequisite for
every other op in this package.

### Reopen_Component_Assignment
When the user rejects a slot, re-code it with their correction recorded in
user_corrections. The profile stays provisional throughout.

### Ask_Targeted_Clarification
When evidence_sufficiency is insufficient for a binding constraint, ask one
precise probe (e.g., "Is it that you don't know how, or that there's no time?")
instead of guessing or over-asking.

### Downgrade_To_Hypothesis
If any emitted language drifts from hypothesis to verdict ("the problem is
your motivation" → "hypothesis: a motivation signal is present"), reframe
immediately and re-label.

### Seed_From_TDF_Grid
If a TDF barrier grid already exists, compress it (14→3) to seed the
component profile instead of re-coding from scratch. Reverse direction of the
usual decomposition.

### Separate_Evidence_Interpretation_Implication
Rebuild any contested slot into disciplined layers: quote → component →
salience → what it implies for design. The user can then correct one layer
without rejecting the whole profile.
