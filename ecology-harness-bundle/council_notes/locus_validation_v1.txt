## PART 2 — Unsupported / overstated claims found in the report or package (with caveats to add)

1. **"78 sources fetched and verified against live journal APIs" — report_discord_draft_v1.md:43. OVERSTATED (the row-1 class).**
   Truth: 78 numbered entries; 69 VERIFIED, 4 RECONSTRUCTED, 2 UNVERIFIED, 3 canonical anchors not fetched (Annotated_Bibliography.md:5 "70+ sources fetched"; entry statuses at [22],[27],[28],[39],[40],[75],[76]–[78]). The campaign's own Calibration_Log row 1 corrected this exact wording in the README.
   → Caveat: "78 sources catalogued with per-entry flags (69 VERIFIED, 4 RECONSTRUCTED, 2 UNVERIFIED, 3 canonical anchors not fetched); ~70 fetched and checked against live journal APIs."

2. **"evidence/Calibration_Log.md — 22 corrections, each recorded as finding → fix → verifier guard" — GitHub_PoC/README.md:91, 137. OVERSTATED as a package contents claim.**
   Truth: the shipped PoC file is a **curated 11-row extract** (rows 1,5,6,7,9,10,15,17,18,19,22); the full 22-row log lives only in the archive (Phase8_Evaluation/Calibration_Log.md). The PoC file itself is honest (GitHub_PoC/evidence/Calibration_Log.md:3 "The full 22-row log lives in the working archive"), but a package reader counting rows will find 11, contradicting the README's "22 corrections... ← the 22-row finding→fix→guard record".
   → Caveat: "evidence/Calibration_Log.md — curated extract (11 of the 22 rows); full log in the archive."

3. **"Quick start" is not executable from the package — GitHub_PoC/README.md:145–156. UNSUPPORTED.**
   Truth: the package ships only README, docs/, evidence/, LICENSE (package tree, README:129–141; find output). `cp -r skills/* ~/.hermes/skills/` and `python3 verify/verify_harness.py` reference `skills/` and `verify/` directories that **do not exist in the package** (they live in Hermes_Agent_Harness/ in the archive).
   → Caveat: "Quick start requires the full estate from the archive (skills/ and verify/ do not ship in this PoC extract)" — or ship them.

4. **"the spirit gate, intensity profile, and preserved-user-decision debrief are all runtime enforced by the artifacts themselves" — GitHub_PoC/README.md:154–156. OVERSTATED.**
   Truth: the artifacts *declare* these invariants; there is no execution layer. Q11 (boundary-gate execution) is explicitly open (judge_deepseek_whole_project.txt:226–231 "A declared firewall is not a working firewall"; PoC Calibration_Log standing item Q11 "DECISIONED (wire it, Phase 9)"); the coach/persona module "is specified but not implemented as code — it is a Hermes-skill contract" (judge:191); verify_phase6 checks file presence/flags, not runtime behavior.

5. **"Phase 1–8: COMPLETE and verified" — GitHub_PoC/README.md:171. OVERSTATED without the judge's own caveats.**
