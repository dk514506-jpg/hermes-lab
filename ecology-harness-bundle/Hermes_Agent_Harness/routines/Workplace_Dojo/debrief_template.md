# Debrief Template (debrief_template.md) — Workplace Communication dojo

Phase 6 required artifact. Debriefs are evidence-grounded and provisional: every
claim anchors to turns; the user corrects the record. Extends the ConvoDojo debrief
template with workplace-specific calibration (power gradient, channel, carry-forward).
Evidence flags: EasyMED 2025 VERIFIED, AgentForge 2026 VERIFIED (role-play mechanism);
debrief structure and power-gradient calibration RECONSTRUCTED.

## Session Header
- Session id / date / practice_target / scenario_id / persona_id
- Meeting format (1:1 | group | written/email-equivalent) and channel
- Intensity profile used (start → end) and any de-escalation events (incl. over-deference)
- Coaching mode (off / on / on_demand) and interruption count

## 1. What Happened (evidence layer)
- Stage transitions (dialogue_state_machine record; note which focus mode, if any)
- 2–5 anchor turns: user utterance + persona response + what the turn shows
- Pressure events (if stress test): cumulative degradation observations

## 2. Rubric Lenses (lens layer — not verdicts)
For each rubric dimension scored (professional_clarity_v1 / feedback_effectiveness_v1 /
workplace_negotiation_align_v1):
- Dimension, lens level (developing / practicing / proficient)
- Evidence quotes (≥1 per score)
- Practice direction: ONE next-step focus the user chooses

## 3. Patterns Noticed (hypothesis layer)
- Patterns from turns only, marked HYPOTHESIS, with turn citations
- Explicit note: "These are hypotheses about this session, not verdicts about you."

## 4. Intensity and Challenge Calibration
- What pushback landed well (evidence)
- What pushback missed / overshot (evidence)
- **Power-gradient calibration**: did the manager/stakeholder persona overwhelm or
  over-defer? Were over-deference markers recorded? (If yes, next session: lower
  intensity, or a peer persona.)
- Recommended intensity for next session (user decides)

## 5. Transfer Notes
- If transfer_flag: what generalized, what did not (evidence-anchored)
- Channel note: if the transfer was written/email-equivalent, did the user rely on
  tone/body cues that would be absent in writing?
- Suggested next transfer context (user decides)

## 6. Carry-Forward (workplace-specific)
- What the user plans to use in the real workplace conversation (their own words)
- Boundary reminder (recorded once): all decisions, commitments, and lines in the real
  conversation belong to the user; the dojo rehearses options, it does not authorize
  real-world words.

## 7. Preserved User Decision (boundary record)
What stays with the user, recorded once per debrief (HEB preserved_user_decision set;
empowerment_boundary.md §3.2):
- All commitments, decisions, and lines for the REAL workplace conversation — the dojo
  rehearses options, it never authorizes real-world words.
- Interpretation of their own performance: rubric feedback is offered, never imposed.
- What to practice next, at what intensity, and when to stop.

## 8. User Verdict Section
- What the user wants to keep, drop, or change from this debrief
- Any corrections to the record (recorded verbatim)

## 9. Calibration Log Entry
- For the agent: sycophancy events, over-deference events, intensity mis-calibrations,
  rubric misreads (overreach signals for the ConvoDojo recovery ops)

---
Template end. The debrief is provisional until the user reviews it.
