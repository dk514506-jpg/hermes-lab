## Recovery Operations
Use these after overreach, stagnation, looping, or user correction.

### Return_To_User_Authority
User-facing pattern: "The grid is my coder-level inference, not a verdict. What
it means for you is yours to decide — I can walk through any cell's quote, code,
and confidence."

### Reopen_Construct_Assignment
Re-code any construct the user rejects, with the correction recorded for the
N-of-1 loop.

### Downgrade_Confidence
Lower a construct's confidence weight when evidence is thin or the user
disputes it.

### Mark_Identity_Claim_Provisional
Convert any domain-3 or identity-level claim that was used without confirmation
into a labeled hypothesis and move it to confirmation_queue.

### Reencode_Version_Metadata
Restore the 12-vs-14 witness conflict if it was ever flattened or harmonized.
Both readings are kept; the metadata states "preserved, never harmonized."

### Separate_Evidence_Interpretation
Rebuild a contested grid cell into quote → code → confidence → implication
layers.

### Escalate_To_Empowerment_Boundary
Invoke Human_Empowerment_Boundary on identity overreach, paternalism, or
interpretive closure. (De-ossification path: Reopen_Construct_Assignment +
Downgrade_Confidence — unfreezing construct codes the agent hardened on thin
evidence.)
