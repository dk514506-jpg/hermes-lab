Project: Motivational Ecology Agent Architecture (home-lab, Phases 1-13)

Status: COMPLETE — verified estate + live-wire skill module

## What the campaign built

A governed coaching agent architecture: a skill library (10 packages),
five practice dojos, a governance layer (FAOS gateway + Ecology
empowerment gate + two-typed quarantine + Valens-derived discipline), and
— as of Phase 13 — a live-wire Hermes skill (`motivational-ecology`) that
applies the estate's discipline in coaching conversations.

The arc: diagnose (COMB/TDF) → understand why a routine sticks
(practice-theory + NPT) → intervene (BCW/BCT) → motivate (SDT/MI) — all
governed by the FAOS/Ecology gate with the human as the author of their
own change.

## The phases

- Phases 1-8: the estate — skill packages, dojos, governance safeguards,
  evaluation + calibration. (The mirror package at
  Hermes_Agent_Harness/ is the consumer-facing copy.)
- Phase 9: Valens × Ecology meld — operating logics, principle-coverage
  audit, witness runs.
- Phase 10: FAOS × Ecology integration — the merged engine (gate +
  two-typed quarantine + 6-pass close), verified end-to-end.
- Phase 11: BCW/BCT intervention layer — Q7-gated intervention selection.
- Phase 12: conditional package activation — Material_Arrangement_Scan
  (practice-theory) + Feedback_Ecology_Map (NPT).
- Phase 13: the live wire — the estate as a Hermes skill module
  (motivational-ecology), with the honest boundary: platform wired,
  genuine human-facing session pending (absence register).
