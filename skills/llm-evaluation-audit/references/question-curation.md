# Question Curation for Persona-Elicitation Evaluations

## Scoring Methodology

Score each candidate question 1-10 on how well it elicits persona-distinctive
responses. Criteria:

- **Room for selective attention.** Can different personas notice different
  things in the same scene?
- **Structural freedom.** Does the question allow different sentence rhythms,
  pacing, and withholding, or does it force a specific format (lists,
  instructions)?
- **Sensory openness.** Does it invite sensory description without priming
  toward a specific valence (warm/cold, pleasant/unpleasant)?
- **Interior access.** Can the answer reveal how the persona processes
  experience, not just what it observes?

## Failure Modes (cut any question exhibiting these)

| Failure mode | Example | Why it fails |
|---|---|---|
| Warmth-priming | "What does a cozy blanket feel like?" | "Cozy" biases toward comfort/warmth. Cold personas must fight the premise. |
| Cold-priming | "What does an empty, frozen landscape feel like?" | Mirror problem — biases toward Saturnine/dry personas. |
| Instructional format | "Explain how to set a table for dinner." | Forces step-by-step structure. Voice is lost. |
| List format | "List five things you might find in a drawer." | Kills narrative pacing and imagery entirely. |
| Yes/no or single-word | "Is this room quiet?" | No room for expression at all. |
| Over-specific scenario | "Describe a red bicycle leaning against a brick wall at noon." | Too many constraints — answers converge. |

## Good Question Archetypes

| Archetype | Example | Why it works |
|---|---|---|
| Blank canvas | "Describe a quiet room." | Silence forces the persona to fill it. |
| Barrier/frustration | "Describe a locked door you can't get through." | Reveals coping style — attack, contemplate, adapt. |
| Interior state | "What passes through your mind just before sleep?" | No external scene to lean on — pure persona filter. |
| Sensory minimal | "What does cold feel like?" | Removes the object; only the sensation remains. |
| Relational silence | "What does silence between two people mean?" | Interpretation reveals values and assumptions. |
| Abstract weight | "Describe the weight of a secret." | Metaphorical — no physical object to describe. |
| Selective attention | "What would you notice first about a stranger?" | Reveals what the persona values or fears. |
| Unchosen circumstance | "How would you prepare for a journey you didn't choose?" | Procedural + emotional — tests coping architecture. |

## Curation Rules

1. Score every question. Cut all below 7.
2. Replacements must match the count — don't shrink the test set.
3. Vary sensory domains: don't make all questions visual or all auditory.
4. Vary cognitive demands: mix descriptive, procedural, narrative, evaluative.
5. Avoid temperature-primed questions entirely — no "warm," "cozy," "comfort,"
   "cold," "frozen," "harsh" in the question text.
6. No instructional or list formats. Ever.
